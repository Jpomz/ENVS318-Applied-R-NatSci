1. Create a scalar named `my_scalar` and give it a value of `TRUE`.  
  * After you assign it, make sure to print or display the object value in the console.  i.e., type `my_scalar` on a new line immediately below the line which assigns it.  
  
2. Create three vectors named `v1`, `v2`, and `v3`. Each vector should have 4 values. Each vector can have whatever values you like, but `v1` should be numeric, `v2` should be logical, and `v3` should be a character.  
  * display all three vectors in your console  
  
3. Make a matrix using `letters`. The matrix should have 2 columns, and the first row should say "a" and "b".  
  * Display your matrix in your console  
  
4. Make a data frame using your three vectors that you created above. The name of each column will be the data type of that column.  
  * display your data frame in your console  
  
5. Make a list out of the objects that you have created in this exercise. The list should display the objects in the same order as the questions., and the names should match the question number For example:  
  * element one will be called "question1", and will be a scalar with the value of `TRUE`  
  * element 2 will be a list called "question2", and will have three elements in it (`v1`, `v2`, `v3`)  
  * etc.
